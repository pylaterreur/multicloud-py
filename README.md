# Generated MultiCloud-Py website

GitHub Pages serves this branch's `/docs` folder. It contains generated static
HTML, not SDK source. `SOURCE_COMMIT` records the source revision for this build.

Maintain Markdown and Python docstrings on `main`, build with MkDocs in strict
mode, then open a publishing PR against `site`. See the source repository's
`docs/maintainers/website.md` for the publishing procedure. Preserve
`docs/.nojekyll` when rebuilding.

Public URL: https://opensource.salesforce.com/multicloud-py/
