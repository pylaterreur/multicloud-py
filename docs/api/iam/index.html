    multicloud.iam¶

    Cloud-agnostic Identity & Access Management. Create identities, attach inline policies, and manage access.

    Cloud-agnostic IAM client package.

    Public entry point — :class:IamClient::

    from multicloud.iam.iam_client import (
    IamClient,
    TrustConfiguration,
    CreateOptions,
)

with IamClient(provider="aws", region="us-west-2") as client:
    identity_id = client.create_identity(
        "MyRole",
        tenant_id="123456789012",
        trust_config=TrustConfiguration(),
        options=CreateOptions(),
    )

    Provider classes (AwsIam, GcpIam) live in sibling distributions (multicloud-iam-aws, multicloud-iam-gcp) and are discovered at runtime via setuptools entry points. They are hidden behind the registry; users never reference them directly.

    CredentialsOverrider dataclass ¶

    CredentialsOverrider(
    credentials_type: CredentialsType,
    session_credentials: Optional[StsCredentials] = None,
    role: Optional[str] = None,
    duration_seconds: Optional[int] = None,
    session_name: Optional[str] = None,
    web_identity_token_supplier: Optional[
        Callable[[], str]
    ] = None,
)

    Override the default credentials resolution.

    Modeled as a grouped configuration object because its fields are interdependent and validated as a unit — the required subset of fields changes based on credentials_type.

    Used when a service needs to: 1. Supply explicit session credentials (SESSION) 2. Assume a role from another account (ASSUME_ROLE) 3. Exchange a web identity token for credentials (ASSUME_ROLE_WEB_IDENTITY)

    If credentials_type is SESSION, session_credentials must be provided. If credentials_type is ASSUME_ROLE, role is required. If credentials_type is ASSUME_ROLE_WEB_IDENTITY, role and web_identity_token_supplier are required.

    role is provider-interpreted: each provider maps this string to its native role identifier format (e.g. an ARN, a service-account email, or a RAM role name).
