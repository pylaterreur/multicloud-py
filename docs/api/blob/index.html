    multicloud.blob¶

    Cloud-agnostic object storage. The user-facing entry points are BucketClient (sync) and AsyncBucketClient (async).

    Sync API¶

    Cloud-agnostic blob client package.

    Public entry point — :class:BucketClient::

    from multicloud.blob.blob_client import BucketClient

with BucketClient(
    provider="aws", bucket="my-bucket", region="us-west-2"
) as client:
    client.upload("hello.txt", b"hi")
    resp = client.download("hello.txt")
    client.delete("hello.txt")

    Switch clouds by changing the provider kwarg only::

    BucketClient(provider="gcp", bucket="my-bucket", region="us-central1")

    Provider classes (AwsBlobStore, GcpBlobStore, ...) live in sibling distributions (multicloud-blob-aws, -gcp, -ali) and are discovered at runtime via setuptools entry points. They are hidden behind the registry; users never reference them directly.

    download_stream ¶

    download_stream(
    key: str,
    *,
    version_id: Optional[str] = None,
    start: Optional[int] = None,
    end: Optional[int] = None
) -> StreamingDownloadResponse

    Download the object as a streaming response for lazy consumption.

    Returns a streaming response that yields content on demand without loading the entire blob into memory. The caller must close the response (preferably via a context manager) to release the underlying HTTP connection.

    Conditional reads (if_match) are supported on download() only; use it when you need an ETag precondition.

    Example::

    with client.download_stream("large-file.bin") as stream:
    for chunk in stream:
        process(chunk)

    Delete all objects under a prefix asynchronously.
