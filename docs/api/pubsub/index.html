    multicloud.pubsub¶

    Cloud-agnostic publish/subscribe messaging. See the Pub/Sub guide for task-focused walkthroughs.

    Cloud-agnostic pubsub client package.

    The user-facing layer: TopicClient and SubscriptionClient plus the value objects callers pass to their operations. Provider-specific code lives in sibling packages (pubsub_aws, pubsub_gcp, pubsub_ali) and is hidden behind the registry.

    SubscriptionClient ¶

    SubscriptionClient(
    *,
    provider: str,
    subscription_name: str,
    region: Optional[str] = None,
    endpoint: Optional[str] = None,
    nack_visibility_timeout: Optional[timedelta] = None,
    credentials_overrider: Optional[
        CredentialsOverrider
    ] = None,
    **provider_kwargs: Any
)

    Cloud-agnostic subscription client for receiving and acknowledging messages.

    The user-facing API surface for subscribing. Construction takes a provider id and a unified set of cloud-agnostic options; the underlying provider class is selected from the registry.

    Parameters:

    Name Type Description Default
    provider str

    Provider id (e.g., "aws", "gcp", "ali"). See the registry for all registered providers.

    		 required
    subscription_name str

    Subscription name/identifier.

    		 required
    region Optional[str]

    Region (interpreted per provider). Optional.

    		 None
    endpoint Optional[str]

    Endpoint override URL. Optional.

    		 None
    nack_visibility_timeout Optional[timedelta]

    Default visibility timeout for nacked messages. Optional; defaults to 0 (immediate redelivery).

    		 None
    credentials_overrider Optional[CredentialsOverrider]

    Override default credential resolution. Optional; used for test isolation, cross-account access, or role assumption.

    		 None
    Note

    Credentials are sourced from environment variables or system default credential discovery (environment variables, credential files, or cloud-native authentication like IAM roles or workload identity).

    Use credentials_overrider for structured credential overrides (session credentials, role assumption, web identity). Individual credential parameters (aws_access_key_id, etc.) are not supported.

    		 required
    region Optional[str]

    		 None
    endpoint Optional[str]

    Endpoint override URL. Optional.

    		 None
    credentials_overrider Optional[CredentialsOverrider]

    Override default credential resolution. Optional; used for test isolation, cross-account access, or role assumption.

    		 None
    **provider_kwargs Any

    Additional provider-specific keyword arguments. See provider implementation documentation for available options.

    		 {}
    Note

    Credentials are sourced from environment variables or system default credential discovery (environment variables, credential files, or cloud-native authentication like IAM roles or workload identity).

    Use credentials_overrider for structured credential overrides (session credentials, role assumption, web identity). Individual credential parameters (aws_access_key_id, etc.) are not supported.

    Message dataclass ¶

    Message(
    loggable_id: Optional[str] = None,
    body: Optional[bytes] = None,
    metadata: Dict[str, str] = dict(),
    ack_id: Optional[AckID] = None,
    as_func: Optional[AsFunction] = None,
    before_send: Optional[SendHook] = None,
    after_send: Optional[SendHook] = None,
)

    Message represents a message in the pubsub system.

    Messages contain the actual data being transmitted along with metadata and acknowledgment information when received from subscriptions.

    Message is mutable by design because it is assembled incrementally through the builder and may be enriched during pubsub flow (for example: metadata, acknowledgement id, loggable id, and send hooks). Use Message.builder() to create new messages.

    Attributes:

    Name Type Description
    loggable_id Optional[str]

    Loggable ID for this message (useful for debugging). This is set for received messages. Should not be set for outgoing messages.
    body Optional[bytes]

    The message body content as bytes.
    metadata Dict[str, str]

    A map of metadata key-value pairs.
    ack_id Optional[AckID]

    The acknowledgment ID for this message. Only set for received messages.
    as_func Optional[AsFunction]

    Optional function for driver-specific type conversion.
    before_send Optional[SendHook]

    Optional callback invoked before sending.
    after_send Optional[SendHook]

    Optional callback invoked after sending.
