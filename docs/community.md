# Community and contributors

MultiCloud-Py is maintained by Salesforce and its open-source contributors.
Contributions to SDK implementations, tests, examples, and documentation are
welcome.

## Maintainers

The repository's [CODEOWNERS](https://github.com/salesforce/multicloud-py/blob/main/CODEOWNERS)
identifies the current code owner, [@LihaoLiuXs](https://github.com/LihaoLiuXs).
Use [GitHub issues](https://github.com/salesforce/multicloud-py/issues) for
questions, proposals, and bug reports so the discussion is available to the
community. Maintainer ownership can change; CODEOWNERS is the source of truth.

## Contributors

Thank you to everyone who contributes. See the
[GitHub contributors](https://github.com/salesforce/multicloud-py/graphs/contributors)
for public contribution attribution. A contribution graph does not enumerate
every kind of participation; documentation review, issue reports, and testing
also help the project.

## Get involved

- Read the [contribution guide](https://github.com/salesforce/multicloud-py/blob/main/CONTRIBUTING.md).
- Check the [implementation roadmap](roadmap.md) and existing issues before
  proposing a feature.
- Follow the [code of conduct](https://github.com/salesforce/multicloud-py/blob/main/CODE_OF_CONDUCT.md).
- Use the [security policy](https://github.com/salesforce/multicloud-py/blob/main/SECURITY.md)
  to report a vulnerability through the designated channel.
